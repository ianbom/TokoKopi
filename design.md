# Declasse Coffee — Design System

## Overview

Declasse Coffee uses a **contemporary editorial coffee-commerce design system** built around warm neutrals, deep forest green, restrained terracotta accents, structured modular grids, premium product photography, and strong typography.

The site should feel like a **specialty coffee brand presented through the visual language of an independent fashion and lifestyle magazine**: refined, tactile, calm, confident, modern, and highly art-directed.

The design must avoid the visual conventions of generic coffee shops and generic e-commerce templates. Declasse should not feel rustic, overly brown, overly rounded, playful, SaaS-like, or dependent on decorative effects. Visual strength should come from:

- typography,
- grid composition,
- whitespace,
- thin borders,
- cinematic photography,
- asymmetric layouts,
- controlled color usage,
- and product-first storytelling.

The website name and primary wordmark are:

**Declasse**

The wordmark should feel elegant, editorial, and distinctive. Use a high-contrast serif for the logo while the rest of the interface relies mostly on contemporary sans-serif typography.

### Core Visual Identity

Declasse uses a **five-color editorial palette**:

- **Warm Cream** (`{colors.canvas}` — `#FAF6EE`) for the main page background and dominant product surfaces.
- **Warm Sand** (`{colors.sand}` — `#F2E7D8`) for alternate sections, editorial blocks, and tonal contrast.
- **Deep Forest** (`{colors.ink}` — `#1F2923`) for main typography, navigation, dark sections, footer, buttons, and structural emphasis.
- **Soft Oat** (`{colors.oat}` — `#DDD0BA`) for secondary surfaces, image backdrops, selected states, and low-contrast editorial areas.
- **Burnt Terracotta** (`{colors.primary}` — `#B65C3A`) for calls-to-action, selected states, small promotional accents, subscription sections, and interaction highlights.

### Key Characteristics

- **Editorial grid system:** content is organized with strict vertical and horizontal dividers instead of floating cards.
- **Warm minimalism:** warm cream and sand replace clinical white.
- **Deep forest structure:** forest green replaces pure black as the dominant dark tone.
- **Restrained terracotta:** terracotta is used sparingly so it remains visually powerful.
- **Product-first photography:** coffee bags, cans, pouches, brewing scenes, and lifestyle photography dominate.
- **Asymmetric composition:** split-screen and modular editorial layouts are preferred over centered SaaS sections.
- **Typography-driven hierarchy:** oversized condensed headlines paired with elegant serif brand typography.
- **Thin-border UI:** use 1px dividers and outlines rather than heavy shadows.
- **Low-radius surfaces:** most elements are square or nearly square.
- **Fashion-editorial imagery:** photography should feel closer to a premium campaign or architecture magazine than a traditional café advertisement.
- **Commerce clarity:** browsing, filtering, purchase options, cart, and checkout remain immediately understandable.

## Typography

### Typeface Direction

Declasse should combine **editorial elegance with modern utility**.

Use three typographic roles:

1. **Brand Serif** — wordmark, occasional editorial accent.
2. **Condensed / Grotesk Display** — hero headings, campaign titles, section statements.
3. **Clean Sans Serif** — body, navigation, filters, forms, commerce UI.

### Recommended Font Stack

#### Interface / Body

```css
font-family: Inter, "Helvetica Neue", Arial, system-ui, -apple-system, BlinkMacSystemFont, sans-serif;
```

#### Editorial Headings

```css
font-family: "Arial Narrow", "Helvetica Neue", Arial, sans-serif;
font-stretch: condensed;
```

When available, use a licensed or project-approved condensed grotesk such as:

- Archivo Narrow
- Roboto Condensed
- Barlow Condensed
- Neue Haas Grotesk Display
- Trade Gothic Condensed

#### Brand / Serif Accent

```css
font-family: "Instrument Serif", "Cormorant Garamond", Georgia, serif;
```

Use the serif primarily for:

- Declasse wordmark,
- editorial numerals,
- occasional pull quotes,
- select campaign accents.

Do not use serif for every heading.

### Typography Principles

- Use **large condensed uppercase headings** as the primary visual signature.
- Keep body copy compact, readable, and understated.
- Navigation should be small, calm, and uppercase.
- Avoid excessive bolding.
- Product names should feel refined rather than loud.
- Prices should not dominate the product name.
- Use serif only where it strengthens editorial character.
- Use whitespace as part of the typography system.
- Large headings may intentionally break across 2–4 lines.

### Product Naming Pattern

Use clean, restrained naming:

```txt
{Product / Origin / Blend} {Optional Number}
```

Examples:

- `ESPRESSO NO.01`
- `LATTE NO.02`
- `FILTER NO.03`
- `DECAF NO.04`
- `ETHIOPIA`
- `COLOMBIA`
- `HOUSE BLEND`
- `NIGHT DECAF`
- `SILK LATTE CAN`
- `TRAVEL BREW PACK`

Tasting notes appear below product names:

```txt
Chocolate · Hazelnut · Caramel
```

## Layout

### Spacing System

- **Base unit:** 4px
- `{spacing.xs}` — 4px
- `{spacing.sm}` — 8px
- `{spacing.md}` — 12px
- `{spacing.base}` — 16px
- `{spacing.lg}` — 24px
- `{spacing.xl}` — 32px
- `{spacing.2xl}` — 48px
- `{spacing.section}` — 72px
- `{spacing.hero}` — 104px

### Grid

- **Desktop base grid:** 12 columns
- **Desktop page width:** 100%
- **Recommended max editorial width:** 1440px
- **Catalog max width:** 1600px
- **Grid gutter:** usually 0–24px depending section
- **Main side padding desktop:** 32–48px
- **Tablet:** 24px
- **Mobile:** 16px

Declasse should often use **full-bleed modular sections with internal borders** rather than placing every section inside an isolated max-width card.

### Border Philosophy

Use thin rules to define hierarchy:

```css
border: 1px solid rgba(31, 41, 35, 0.18);
```

Preferred:

- vertical product grid dividers,
- horizontal editorial separators,
- outlined buttons,
- input borders,
- section grid boundaries.

Avoid excessive floating containers.

### Corner Radius

The default Declasse interface is intentionally sharp.

- Product cards: `0–2px`
- Buttons: `0–9999px` depending role
- Small editorial outline CTAs may use pill radius.
- Inputs: `0–2px`
- Modals: `0–6px`
- Image blocks: normally `0px`

Do not use large 16–32px rounded corners throughout the UI.

### Whitespace Philosophy

The interface should feel **spacious but structured**.

- Large text sections need generous negative space.
- Product grids can be dense but must never feel cramped.
- Use visual pauses between campaign sections and catalog rows.
- Let photography extend to grid edges.
- Avoid stacking too many unrelated UI controls inside cards.

## Elevation

Declasse should remain mostly flat.

### Shadow Tokens

- **None** (`{shadow.none}`): default.
- **Subtle** (`{shadow.subtle}`): `0 1px 2px rgba(31,41,35,0.06)` — sticky header or tiny utility.
- **Dropdown** (`{shadow.dropdown}`): `0 10px 28px rgba(31,41,35,0.14)` — menus only.
- **Modal** (`{shadow.modal}`): `0 24px 64px rgba(31,41,35,0.20)` — modal / cart drawer if needed.

### Elevation Rules

- Product cards: no shadow.
- Main sections: no shadow.
- Use borders before elevation.
- Dropdowns and floating overlays may use shadow.
- Avoid floating white cards over cream backgrounds.

## Interactions

### Hover

- Nav links: underline or terracotta shift.
- Text CTAs: arrow moves 4–6px.
- Product image: scale 1.02–1.03.
- Product card: very subtle background shift from cream to soft sand.
- Footer links: terracotta.
- Primary forest button: terracotta.
- Outline CTA: forest fill.

### Active

- Active category: forest or terracotta text.
- Selected variant: forest fill.
- Selected subscription: terracotta outline / soft fill.
- Active menu: subtle underline.

### Focus

- Inputs: 2px forest outline or clear forest border.
- Buttons: visible focus ring using forest/terracotta.
- Links: underline + focus ring.
- Modal focus must be trapped.

### Disabled

- Text: `#9A9688`
- Border: lighter hairline
- Background: `#E7DED0`
- Disabled variants may use line-through.

### Loading

Use quiet skeleton blocks:

- Background: `#E9E1D5`
- No shimmer if unnecessary.
- Keep layout stable.

### Motion

Default transitions:

- 250–450ms
- ease-out

Avoid:

- springy SaaS animation,
- excessive parallax,
- large bouncing buttons,
- overly animated cursors.

### Reduced Motion

Respect:

```css
@media (prefers-reduced-motion: reduce)
```

Disable marquee movement, hover scaling, and non-essential transitions.

## Accessibility

- Deep Forest on Warm Cream provides the primary readable pairing.
- Do not use terracotta alone to communicate semantic meaning.

## Implementation Principles

When implementing Declasse:

1. Use the grid before adding decorative styling.
2. Use borders before shadows.
3. Keep cream / sand dominant.
4. Keep forest as the structural dark tone.
5. Reserve terracotta for meaningful emphasis.
6. Keep product photography consistent.
7. Avoid over-rounded cards.
8. Avoid visual effects that compete with the coffee.
9. Maintain generous whitespace.
10. Preserve commerce clarity.
11. Use oversized typography selectively.
12. Keep animations slow and restrained.
13. Test mobile product browsing carefully.
14. Maintain consistent product packaging scale across cards.
15. Do not mix unrelated design styles between pages.
